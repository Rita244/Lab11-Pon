## Контрольные вопросы

1. Массив фиксированный (нельзя добавить сверх размера), а List динамический
2. Доступ по индексу [0]. Count — это количество элементов в списке
3. Хранить пары «ключ-значение» (например, «Имя — Телефон») для быстрого поиска
4. Если ключа нет, обычный [key] выдаст ошибку, а TryGetValue просто вернет false (программа не упадет)
5. Хранит только уникальные элементы. Дубликаты не добавляются, потому что коллекция их автоматически проверяет и отбрасывает
6. У них разные задачи: товары — просто список (List); справочник — быстрый поиск по имени (Dictionary); теги — без повторов (HashSet)
7. В Dictionary мы мгновенно найдем балл по имени. В List пришлось бы перебирать всех студентов циклом
